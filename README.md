# ValidaAuto — Landing Page

Landing page mobile-first para o funil de teste de conhecimentos em mecânica automotiva.

## Stack
- React + TypeScript
- Vite
- CSS puro
- Lucide React

## Rodar no VS Code

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite, normalmente `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```
